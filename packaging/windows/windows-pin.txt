# BRANDED PAYLOAD EXE (field defect fix): the Windows taskbar shows the
# window icon, which comes from thunderbird.exe's OWN icon-resource group —
# so the stock build showed the Thunderbird logo while running. Icon group
# 32512 is rebuilt from our .ico by icon-patch.ps1 (real Windows only).
# TRADEOFF, on the record: rewriting a resource invalidates Mozilla's
# Authenticode signature on thunderbird.exe, so it is stripped first and the
# modified exe is RE-SIGNED with the Dosvak LLC EV certificate (Sectigo Public
# Code Signing CA EV R36) and RFC3161-timestamped — one trusted signature
# replaced by another. Every OTHER payload binary (xul.dll etc.) still carries
# Mozilla's original signature, byte-identical.
#
# That trade only became true on 2026-08-21. Before it, the re-signature was
# the QuickOpen Root CA — our own root, trusted by no Windows machine — so we
# had in fact swapped Mozilla's trusted signature for one SmartScreen treats as
# no signature at all. packaging/windows/build.sh now REFUSES to pack a payload
# that is not signed by CN=Dosvak LLC, so the trade cannot silently lapse.
